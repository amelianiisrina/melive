A

Pendahuluan

Praktikum ini membahas penggunaan dasar validasi input pada aplikasi untuk memastikan data yang dimasukkan pengguna sesuai dengan ketentuan sebelum diproses oleh sistem. Materi meliputi pengambilan teks melalui controller, penerapan widget dropdown statis, serta validasi untuk mencegah data kosong atau tidak sesuai format. Konsep tersebut diterapkan pada pembuatan interface sederhana yang dapat menerima input pengguna dan memberikan pesan error apabila data yang dimasukkan tidak valid.

B

Tujuan

Pengelolaan Input Pengguna

Mengimplementasikan proses penerimaan teks dari pengguna melalui controller serta menampilkan pilihan menggunakan widget dropdown statis.

Validasi Data Input

Menerapkan validasi pada data yang dimasukkan pengguna untuk memastikan data tidak kosong dan sesuai dengan format yang telah ditentukan.

D

Langkah Kerja

1
Membuat File Baru

Buat file dart baru dengan nama add_transaction_screen.dart.

2
Membuat Form Input Transaksi

Menyusun form untuk mencatat transaksi yang mencakup input judul, nominal, kategori, tanggal, serta validasi data.

3
Mengatur Konfigurasi Aplikasi

Mengatur tema, judul aplikasi, serta menentukan AddTransactionScreen sebagai halaman utama aplikasi pada main.dart.

4
Jalankan Program

Jika dijalankan maka akan muncul tampilan seperti gambar berikut.

E

Tugas

1
Input Tanggal

Tambahkan satu input baru sebelum tombol Simpan untuk mengisi tanggal transaksi. Dapat menggunakan TektFormField biasa atau showDatePicker.

F

Kesimpulan

Praktikum ini berhasil menerapkan pembuatan form transaksi pada Flutter dengan menggunakan input teks, dropdown, dan pemilihan tanggal. Validasi input juga diterapkan untuk memastikan data yang dimasukkan sesuai dengan ketentuan sebelum diproses oleh aplikasi.
