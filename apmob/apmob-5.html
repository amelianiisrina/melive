A

Pendahuluan

Praktikum ini membahas penggunaan Named Routes dan Bottom Navigation Bar pada aplikasi Flutter. Materi meliputi penggunaan routes untuk mendefinisikan rute setiap halaman dan initialRoute untuk menentukan halaman pertama yang ditampilkan. Selain itu, praktikum membahas penggunaan Bottom Navigation Bar untuk memudahkan perpindahan antarhalaman utama melalui ikon dan label navigasi. Konsep tersebut diterapkan pada pembuatan aplikasi sederhana yang memiliki navigasi terstruktur sehingga pengguna dapat berpindah antarhalaman dengan lebih mudah dan terorganisasi.

B

Tujuan

Penerapan Named Routes

Menerapkan Named Routes untuk mengatur navigasi antarhalaman secara terpusat, terstruktur, dan rapi.

Bottom Navigation Bar

Membangun menu navigasi di bagian bawah layar menggunakan BottomNavigationBar untuk memudahkan perpindahan antarhalaman.

Integrasi Halaman

Mengintegrasikan halaman Dashboard, Riwayat, dan Profil ke dalam satu struktur aplikasi dengan navigasi yang konsisten.

D

Langkah Kerja

1
Konfigurasi Named Routes

Mengatur tema aplikasi serta mendefinisikan rute halaman menggunakan routes dan menentukan halaman awal melalui initialRoute.

2
Pengaturan Main Screen dan Bottom Navigation Bar

Mengatur tampilan Dashboard, Riwayat, dan Profil serta perpindahan tab menggunakan BottomNavigationBar dan setState() untuk memperbarui indeks halaman aktif.

3
Pembaruan Navigasi pada Dashboard

Mengubah navigasi tombol tambah transaksi dari Navigator.push menjadi Navigator.pushNamed agar perpindahan ke halaman form input menggunakan Named Routes /add.
